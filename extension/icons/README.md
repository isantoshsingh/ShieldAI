# Extension Icons

Place PNG icons here:
- icon-16.png  (16×16)
- icon-48.png  (48×48)
- icon-128.png (128×128)

These can be any PNG with a shield or "S" logo. Use a tool like Figma or
the free favicon generator at https://favicon.io to create them.

The extension will work without icons (Chrome will show a default grey square),
but icons make the extension look professional during the pilot.
