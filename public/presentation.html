Security & Privacy

Built for trust. Engineered for isolation.

We collect only what’s needed and nothing more. Every architectural decision prioritises data isolation and minimal footprint.

🚫
No content reading
The extension records domain name and page title only. No prompts, no form values, no keystrokes. Ever.
🔒
Complete tenant isolation
Every database query is scoped through current_organisation. Cross-org access returns 404, not 403. Enforced at controller level.
🛡️
Rate limiting with Rack::Attack
API: 60 req/min per token, 300 req/5min per IP. Signup: 10/hr per IP. Abuse is stopped at the edge.
🔐
Token-based extension auth
Employees never get dashboard credentials. Each gets a unique extension_token that can be regenerated instantly.
🗒️
90-day auto-cleanup
Raw detection events are deleted after 90 days. Aggregated daily summaries are preserved for long-term trends.
✅
Role-based access control
Three roles: super_admin (platform), org_admin (full org access), org_member (read-only). No over-privileged accounts.
